# sewhail.com

My personal website.

**Stack:** Next.js · TypeScript · Tailwind CSS · shadcn/ui

## Update the current read

Edit [`content/current-read.json`](./content/current-read.json), change the
`title`, `author`, local `cover` path, and `coverSource`, then commit the change.
Cover images live in [`public`](./public) and should come from an official
publisher or other reliable listing. Once this branch is merged, the file can
be updated from a phone at:

https://github.com/sewhail/portfolio/edit/main/content/current-read.json
